# Sudoku no navegador

Resolvedor de Sudoku web com preenchimento de tabuleiro e opção de resolução passo a passo.

**Contexto:** Estudo de algoritmos.  
**Tecnologias:** HTML, CSS e JavaScript.

## Visão do projeto

Preencha as posições conhecidas do tabuleiro e use **Resolver** ou **Passo a Passo** para explorar a solução.

## Executar localmente

Clone o repositório e sirva os arquivos localmente. Com Python instalado:

```bash
git clone https://github.com/GuiPaicheco/Sudoku-Autocomplete.git
cd Sudoku-Autocomplete
python -m http.server 8000 --bind 127.0.0.1
```

Abra [http://127.0.0.1:8000/index.html](http://127.0.0.1:8000/index.html). Preserve as pastas de imagens, estilos e scripts. Recursos externos, quando usados pela página, podem exigir conexão com a internet.
